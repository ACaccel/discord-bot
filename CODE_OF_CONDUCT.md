# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
code of conduct. Contributors and maintainers are expected to follow
it in every project space (issues, pull requests, discussions, and any
community channel attached to this repository).

The full text is available at the link below. Please read it before
your first contribution.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

If you experience or witness behaviour that violates this code of
conduct, please report it privately to the project maintainers via the
GitHub repository owner's contact details, or through a GitHub
Security Advisory if the matter is sensitive
(<https://github.com/ACaccel/discord-bot/security/advisories/new>).

All reports will be reviewed and handled confidentially. Maintainers
are obligated to respect the privacy and safety of the reporter.

## Enforcement

Maintainers may take any action they deem appropriate, up to and
including a permanent ban from the project, in response to behaviour
that they consider a violation of this code. The enforcement
guidelines in section 4 of the Contributor Covenant apply.
