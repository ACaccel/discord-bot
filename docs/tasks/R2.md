# R2 任務 — 消除 DI 旁路

> 詳細設計：[docs/design/R2.md](../design/R2.md)　|　需求：[proposal §5](../proposal.md#5-r2--消除-di-旁路)　|　高階設計：[HLD §5](../high-level-design.md#5-r2--消除-di-旁路)

## 先決條件

- [ ] R1 已完成並合進工作分支（BaseBot 已是 thin lifecycle owner）

## 子任務

### 1. IoC token 新增

- [ ] `src/core/ioc/tokens.ts`：新增 `TOKENS.VoiceController`
- [ ] `src/core/ioc/tokens.ts`：新增 `TOKENS.ModelCatalog`

### 2. PluginContext 契約擴張

- [ ] `src/core/plugin/types.ts`：在 `PluginInitContext` 介面加 `registerInstance<T>(token: ServiceToken<T>, instance: T): void`（**只放在 init context**，不放 start / event 的 context — 型別層即可擋住部分誤用）
- [ ] 對應 JSDoc 說明合法時機與重複 register 的政策（reject duplicate）

### 3. Lifecycle 階段守門

- [ ] `src/core/plugin/host/lifecycle.ts`：新增 phase tracking（`'init' | 'start' | 'onReady' | 'running' | 'shutdown'`）
- [ ] 新增 `assertInitPhase()` 守門 helper
- [ ] `buildInitContext` 內 closure 包入 phase 讀取，使 plugin 把 init ctx 偷藏到 start 階段使用時也會被擋下
- [ ] 違規時丟 `ConfigurationError`，code = `LIFECYCLE_PHASE_VIOLATION`，messageKey = `errors:plugin.lifecycle_phase_violation`
- [ ] 新檔 `test/unit/core/plugin/lifecycle-guard.test.ts`：覆蓋 init / start / onReady / event 各 hook 呼叫 registerInstance 的允許 / 拒絕

### 4. i18n 新增 key

- [ ] `src/i18n/locales/zh-TW/errors.json`：新增 `plugin.lifecycle_phase_violation`
- [ ] `src/i18n/locales/en/errors.json`：對應新增同 key
- [ ] catalog-completeness 測試自動驗證 parity

### 5. ServiceContainer 內部接線

- [ ] `src/core/ioc/container.ts` 若需要：暴露一個內部 `registerInstance` helper 讓 host 呼叫；或讓 host 直接以 `registerSingleton(token, () => instance)` 包裝
- [ ] DuplicateRegistrationError 既有語意自動套用

### 6. VoicePlugin 改寫

- [ ] `src/plugins/voice/plugin.ts`：移除對 `setActiveVoiceController` 的 import；`init` 改為 `ctx.registerInstance(TOKENS.VoiceController, new VoiceController(client))`
- [ ] **刪除** `src/plugins/voice/internal/active-controller.ts`
- [ ] `src/plugins/voice/internal/index.ts`：移除 `setActiveVoiceController` / `getActiveVoiceController` 的 re-export
- [ ] `test/unit/plugins/voice.test.ts`（新增或更新）：驗證 plugin init 後 container 可解析 `TOKENS.VoiceController`

### 7. BaseBot.voice getter

- [ ] `src/bot/index.ts`：把 public `voice?: VoiceController` 改為 `get voice(): VoiceController | undefined { return this.container.tryResolve(TOKENS.VoiceController); }`
- [ ] 移除 `run()` 內 `this.voice = getActiveVoiceController()` 的後置同步
- [ ] 同步更新所有 `bot.voice.start(...)` / `bot.voice.stop(...)` 呼叫點（行為等價）

### 8. models-catalog 改寫

- [ ] `src/plugins/llm-chat/plugin.ts`：在 `init` 中建構並 `ctx.registerInstance(TOKENS.ModelCatalog, catalog)`
- [ ] `src/infra/llm/models-catalog.ts`：移除 `setActiveModelCatalog` / `getActiveModelCatalog` 等 module-global 函式；保留 `ModelCatalog` 類別作為純資料持有者
- [ ] 找出所有 `getModelCatalog()` / `listProviderModels()` 的呼叫點，改為從 container（handler 端透過注入的 resolver）取得
- [ ] `test/unit/infra/llm/models-catalog.test.ts`（新增或更新）：覆蓋 catalog 經 DI 取用的 happy path

### 9. 驗證

- [ ] `grep -rn 'let active' src/plugins src/infra` 結果為空
- [ ] `grep -rn 'getActiveVoiceController\|setActiveVoiceController\|getActiveModelCatalog\|setActiveModelCatalog' src` 結果為空
- [ ] 跑全測試 + lint + format
- [ ] 跑 `reliability-reviewer` agent Audit R2 變更，verdict = PASS
